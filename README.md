# 🎓 Delhi Public School Registration Form

## 📖 Project Description
This project is a Delhi Public School Registration Form website.
It is developed using HTML, CSS, and JavaScript.
The form collects student details like name, class, parent details, contact information, etc.

## 🚀 Features
- Student Registration Form
- Input Validation using JavaScript
- Responsive Design
- Clean and User-Friendly Interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- VS Code
- Git & GitHub
